# EaseShop – E-Commerce Shopping Prototype

## About the Project
EaseShop is a full-stack e-commerce shopping prototype developed to explore web development, backend programming, and database integration.

## Technologies Used
- HTML
- CSS
- JavaScript
- Node.js
- Express.js
- MySQL

## Project Features
- Customer registration and login
- Product browsing
- Shopping interface
- Admin login and management interface
- Backend integration
- MySQL database connectivity

## Project Structure
- Frontend: HTML, CSS, JavaScript
- Backend: Node.js and Express.js
- Database: MySQL

## Installation and Setup
1. Clone this repository.
2. Open the project folder.
3. Install dependencies using `npm install`.
4. Configure your MySQL database connection.
5. Start the server using `node server.js`.
6. Open `http://localhost:3001` in your browser.
